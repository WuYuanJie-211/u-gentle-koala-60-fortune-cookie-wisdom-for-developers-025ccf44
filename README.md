A single original line of fortune-cookie wisdom for a software developer,
written for the make.fun bounty "Fortune Cookie Wisdom for Developers".

> You will deploy on Friday at 4:59 p.m., and the pager will sing your name before the pizza arrives.

## Run

```sh
npx tsx main.ts
```

This writes the line to `/output/entry.txt`.

## Entry

- Competition: [Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44)
- Line: 99 characters, one line, within the 120-character limit.
- The program checks the length gate itself before writing the output file.
